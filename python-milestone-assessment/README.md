# Python Milestone Assessment
 
## Overview
This repository contains solutions to two Python programming assessment questions.
 
## Project Structure
- question1/: Student Marks Management System
- question2/: Employee File Management System
 
## Question 1
Calculates student totals, averages, grades, and results. Finds the highest-scoring student and lists students with averages above 75.
 
## Question 2
Stores and reads employee details from a text file. Displays employee records, identifies employees earning above ₹50,000, finds the highest-paid employee, and counts employees by role.
 
## How to Run
Install Python 3.
 
For Question 1:
cd question1
python main.py
 
For Question 2:
cd question2
python main.py
 
## Concepts Covered
- Lists and dictionaries
- Functions
- Conditional statements and loops
- List comprehension
- Classes and objects
- File handling
- Exception handling
